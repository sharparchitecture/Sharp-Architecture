# S#arp Architecture

![S#arp Architecture](_static/sharp_arch.jpg)

S#arp Architecture is a solid architectural foundation for rapidly building
maintainable ASP.NET Core web applications, built around Domain-Driven Design on top of
NHibernate.

If you're getting into S#arp Architecture for the first time, follow the docs below
from top to bottom to get a firm understanding of the framework and get yourself set up
with your own S#arp project.
